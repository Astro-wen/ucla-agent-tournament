# 宝可梦「突袭开关」新种子确认：结论 **不合并**

写于 2026-10-16 01:15 PDT（08:15 UTC），云端评估机。被测提交：`pk/lech-1015` 的 21eaae9，开关 `ARENA_SEARCH_SUCKER`（默认关）。

## 一句话结论

在没用过的新种子 197 上，打开开关后对 meta 对手 **显著变差**（胜率 71.3% 降到 65.3%，差 −6.0 个百分点，95% 置信区间 [−11.0, −1.0]，p = 0.035），对 champion 也略差（不显著）。合并标准要求「至少对一个对手显著变强，且对任何对手都不显著变差」，两条都没达到，所以 **不合并**，主线宝可梦保持现状，开关保持默认关。

## 1. 名词解释

- **突袭（Sucker Punch）**：我方仆刀将军（Kingambit）或古剑豹（Chien-Pao）的先制攻击招式。只有对手这一回合选了攻击招式才会成功，对手用变化招或守住时就「落空」（日志里记为 fail）。
- **这个开关做什么**：我方的对战搜索会把对手的几种可能行为混合起来考虑（「混合对手模型」，其中一部分是「贪心对手」，即假设对手出伤害最高的招）。开关打开后，搜索表里含突袭的那一行，贪心部分的权重乘以 (1 − q)，q 是估计的对手本回合不攻击的概率。目的：少在对手可能不攻击时用突袭。
- **种子（seed）**：决定发牌（18 张卡池、双方选秀顺序等）的随机数起点。种子 127 是开发时用来调参的，可能「看过答案」；197 是新种子，用来做独立确认。
- **配对比较**：基线（开关关）和候选（开关开）打 **完全相同的牌局**，逐局比胜负。只看「一方赢、另一方输」的局（叫「不一致对」），比纯比胜率更灵敏。
- **95% 置信区间（CI）**：真实差值大概率落在这个范围内。区间整体在 0 以下 = 显著变差，整体在 0 以上 = 显著变强，跨过 0 = 说不准。
- **p 值（符号检验）**：如果开关其实没有作用，出现这么偏的不一致对的概率。小于 0.05 通常算显著。

开关确实让突袭用得少了一半，对 meta 的落空率也下降了（51% 降到 40%）。但胜率反而下降：少用的那些突袭里，有不少本来是成功的（meta 上成功次数从 53 降到 33）。也就是说，突袭落空的代价没有我们想的那么大，而它命中时的收益（先制收割残血）被开关一起砍掉了。对 champion，落空率没有改善（样本很小）。

## 6. 结论和理由

**不合并。** 理由：

1. 合并标准第二条「对任何对手都不显著变差」被违反：对 meta −6.0 [−11.0, −1.0]，p = 0.035。
2. 合并标准第一条「至少对一个对手显著变强」也没达到：两个对手都是负数。
3. 合并后的整体差值 −4.8 [−8.3, −1.3]，p = 0.012，同样显著为负。

因为没有通过测量，按交接说明没有跑开关打开时的上线检查（pytest / 真实重放），也没有改默认值、没有合并、没有推 main。开关在代码里仍是默认关，不影响线上行为。
